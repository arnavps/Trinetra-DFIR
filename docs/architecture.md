# UniDVR-Forensics — Technical Architecture Document

## 1. Overview & System Mission

**UniDVR-Forensics** (SIH26150) is an offline, desktop-native forensic acquisition, recovery, and analysis platform designed specifically for surveillance Digital Video Recorders (DVRs) and Network Video Recorders (NVRs).

Modern CCTV recorders do not utilize standard operating systems or NTFS/FAT filesystems; instead, they employ proprietary, unfragmented, sector-aligned raw disk formats (such as Hikvision HIKFAT or Dahua DHFS) or raw circular sector buffers. UniDVR-Forensics provides forensic investigators with raw block-level acquisition, proprietary filesystem parsing, NAL-unit frame carving, in-memory stream decoding, AI analytics, and legal compliance drafting under Bharatiya Sakshya Adhiniyam (BSA 2023 Section 63) and ISO/IEC 27037.

---

## 2. Core Architecture Invariants & Boundaries

1. **100% Offline Air-Gapped Operation**: No runtime network calls, zero telemetry, no remote licensing, and no cloud dependencies.
2. **CPU-Only Laptop Target**: All binary parsing, video decoding, and AI inference run locally on standard CPU hardware without requiring GPU acceleration.
3. **Primary Evidentiary Path Preservation**:
   - Evidentiary video streams are **never converted, transcoded, or remuxed** on the primary acquisition, parsing, carving, playback, or analysis path.
   - Primary video decoding is performed **in-memory only** via `app/engine5_playback/decoder.py`.
   - `app/engine5_playback/remuxer.py` is invoked strictly by `app/engine9_ui/export_module.py` on explicit investigator request for non-evidentiary derivative exports.
   - Derivative exports receive an independent SHA-256 hash, a dedicated audit log entry, and the prominent label `"convenience copy - not for submission as primary evidence"`.
4. **Read-Only AI Advisory Lane**: Engine 8 AI analytics (YOLOv8n, SCRFD, OSNet, VeRi-776, ANPR, CLIP FAISS) functions as a strictly read-only annotation lane. Annotations are stored in dedicated SQLite tables (`detections`, `face_detections`, `person_reid_embeddings`, `plate_detections`, `vehicle_reid_embeddings`) in `engine7_case_db`. Evidence files and evidence hash chains are never modified.
5. **Non-Self-Certifying Compliance Drafting**: BSA 2023 Section 63 draft certificates generated by `app/engine10_compliance/bsa_sec63.py` are explicitly framed as technical drafts requiring human investigator signature, never self-certifying.

### Module Responsibilities:

- **Engine 1 (`app/engine1_acquisition`)**: Hardware write-blocker verification (`writeblock_check.py`), raw block-level chunked acquisition, and streaming MD5/SHA256 hash computation via `unidvr_rustcore` Rust PyO3 bindings.
- **Engine 2 (`app/engine2_detector`)**: Deterministic OEM signature matcher (`signature_matcher.py`) scanning sector offsets against `signatures.json` with a Random Forest fallback sector classifier (`fallback_classifier.py`).
- **Engine 3 (`app/engine3_parsers`)**: Proprietary filesystem parsers implementing `FileSystemParser` (`hikfat_parser.py`, `dhfs_parser.py`, `generic_parser.py`).
- **Engine 4 (`app/engine4_carver`)**: Sector-level NAL unit scanner (`frame_carver.py`) and raw GOP reconstructor (`gop_reconstructor.py`) extracting elementary video streams without container repackaging.
- **Engine 5 (`app/engine5_playback`)**: SmartCodec bitstream preprocessor (`bitstream_preprocessor.py`), OpenCV/PyO3 in-memory H.264/H.265 frame decoder (`decoder.py`), and container remuxer (`remuxer.py`).
- **Engine 6 (`app/engine6_timeline`)**: On-Screen Display (OSD) timecode extractor (`osd_extractor.py`), classical CV ambient luminance change-point detector (`visual_anchor.py`), and unified per-channel clock normalizer (`normalizer.py`).
- **Engine 7 (`app/engine7_case_db`)**: SQLite WAL-mode case database (`db.py`), dataclass models (`models.py`), and append-only hash-chained Merkle audit log (`audit_log.py`).
- **Engine 8 (`app/engine8_ai`)**: ONNX model registry (`model_registry.py`), YOLOv8n object detector (`detector.py`), SCRFD face detector (`face.py`), OSNet person Re-ID (`reid_person.py`), VeRi-776 vehicle Re-ID (`reid_vehicle.py`), two-stage ANPR pipeline (`anpr.py`), CLIP ViT-B/32 FAISS semantic search (`semantic_search.py`), and single-frame crop enhancer (`enhance.py`).
- **Engine 9 (`app/engine9_ui`)**: PySide6 Fluent-Widgets desktop application (`main_window.py`), case dashboard, 8-tile playback matrix (`playback_matrix.py`), disk hex viewer, search panel (`search_panel.py`), 2-camera suspect journey mapping (`suspect_journey_view.py`), and derivative export module (`export_module.py`).
- **Engine 10 (`app/engine10_compliance`)**: BSA 2023 Section 63 Part A/B draft certificate generator (`bsa_sec63.py`), ISO/IEC 27037 phase mapper (`iso27037_mapper.py`), and ReportLab PDF report builder (`report_builder.py`).
- **Security (`app/security`)**: Subprocess isolation sandbox (`sandbox.py`), cryptographic verification (`crypto.py`), and network watchdog (`network_watchdog.py`).
